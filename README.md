# Lumo

Live wallpapers for Mac. Your own photos, videos and GIFs as living desktops — local, quiet, light on battery.

**[Download the latest release](https://github.com/mahsumozer/lumo-release/releases/latest)**

Requirements: macOS 14 Sonoma or later, Apple silicon.

## Install

1. Open the `.dmg`
2. Drag **Lumo** to your **Applications** folder
3. Launch Lumo from Applications; it lives in the menu bar
